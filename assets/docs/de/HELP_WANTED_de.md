# Hilfe gesucht: Entwickler werden gebraucht! 🚀

Ich kann nur so viel tun! **Aquarium AI** wächst, und ich brauche talentierte Entwickler,
um dieses Projekt auf die nächste Stufe zu bringen.

## Womit wir Hilfe brauchen

### 1. Werbung für zahlende Nutzer entfernen

Wir müssen ein System implementieren, das Benutzern, die das Projekt unterstützen möchten,
eine werbefreie Erfahrung ermöglicht. Dazu gehören:

- Erstellen eines Zahlungs-/Abonnementsystems
- Implementierung der Werbeentfernungslogik basierend auf dem Benutzerstatus
- Verwaltung von Benutzerabonnements und -käufen
- Sicherstellung einer reibungslosen Benutzererfahrung für Premium-Nutzer

### 2. Komplexe Fischintegrationsfunktionen

Erweiterte Fischdatenbankintegration und intelligente Funktionen hinzufügen:

- Erweiterte Fischdatenbank mit detaillierten Arteninformationen
- Erweiterte Kompatibilitätsalgorithmen unter Berücksichtigung mehrerer Faktoren
  (Temperament, Wasserparameter, Ernährung, Größe usw.)
- Intelligentes Tankmanagement und Besatzempfehlungen
- Artspezifische Pflegeleitfäden und Warnungen
- Interaktiver Fischauswähler mit Filter- und Suchfunktionen
- Tank-Simulationsfunktionen
- Krankheitserkennung und Behandlungsempfehlungen

## Erste Schritte

1. **Das Repository forken** auf GitHub
2. **Ihren Fork klonen** lokal
3. **Die Entwicklungsumgebung einrichten** (siehe README.md für Flutter-Setup)
4. **Ein Issue oder eine Funktion auswählen**, an dem/der Sie arbeiten möchten
5. **Einen Branch erstellen** für Ihre Arbeit
6. **Ihre Änderungen vornehmen** mit klaren, fokussierten Commits
7. **Gründlich testen** auf mehreren Plattformen, wenn möglich
8. **Einen Pull Request einreichen** mit einer klaren Beschreibung

## Welche Kenntnisse sind hilfreich?

- **Flutter/Dart** – Die App ist mit Flutter entwickelt
- **Firebase** – Wir nutzen Firebase für Backend-Dienste
- **Zahlungsintegration** – Erfahrung mit In-App-Käufen (iOS/Android)
- **Datenbankdesign** – Für Fischdatenbank und Kompatibilitätssysteme
- **API-Integration** – Arbeiten mit AI-APIs (Gemini, OpenAI usw.)
- **UI/UX-Design** – Die App schön und intuitiv gestalten

## Code-Richtlinien

- Den bestehenden Code-Stil und die Struktur einhalten
- Klare, beschreibende Commit-Nachrichten schreiben
- Kommentare für komplexe Logik hinzufügen
- Dokumentation bei Bedarf aktualisieren
- Änderungen gründlich testen
- PRs auf eine einzelne Funktion oder einen Fix fokussiert halten
