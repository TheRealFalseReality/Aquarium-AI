# Se busca ayuda: ¡Se necesitan desarrolladores! 🚀

¡Solo puedo hacer tanto! **Aquarium AI** está creciendo y necesito desarrolladores talentosos
que ayuden a llevar este proyecto al siguiente nivel.

## Con qué necesitamos ayuda

### 1. Eliminar anuncios para usuarios de pago

Necesitamos implementar un sistema que permita a los usuarios que quieran apoyar el
proyecto pagar por una experiencia sin anuncios. Esto implicaría:

- Crear un sistema de pago/suscripción
- Implementar la lógica de eliminación de anuncios según el estado del usuario
- Gestionar suscripciones y compras de usuarios
- Garantizar una experiencia fluida para usuarios premium

### 2. Funciones complejas de integración de peces

Añadir integración avanzada de base de datos de peces y funciones inteligentes:

- Base de datos de peces mejorada con información detallada de especies
- Algoritmos avanzados de compatibilidad que consideran múltiples factores (temperamento,
  parámetros del agua, dieta, tamaño, etc.)
- Gestión inteligente de acuarios y recomendaciones de población
- Guías de cuidado específicas por especie y alertas
- Selector de peces interactivo con capacidades de filtrado y búsqueda
- Funciones de simulación de acuario
- Identificación de enfermedades y recomendaciones de tratamiento

## Primeros pasos

1. **Haz un fork del repositorio** en GitHub
2. **Clona tu fork** localmente
3. **Configura el entorno de desarrollo** (consulta README.md para la configuración de
   Flutter)
4. **Elige un issue** o función en la que trabajar
5. **Crea una rama** para tu trabajo
6. **Realiza tus cambios** con commits claros y enfocados
7. **Prueba exhaustivamente** en múltiples plataformas si es posible
8. **Envía un pull request** con una descripción clara

## ¿Qué habilidades son útiles?

- **Flutter/Dart** – La aplicación está construida con Flutter
- **Firebase** – Usamos Firebase para servicios de backend
- **Integración de pagos** – Experiencia con compras en la aplicación (iOS/Android)
- **Diseño de base de datos** – Para base de datos de peces y sistemas de compatibilidad
- **Integración de API** – Trabajar con APIs de AI (Gemini, OpenAI, etc.)
- **Diseño UI/UX** – Hacer la aplicación hermosa e intuitiva

## Directrices de código

- Seguir el estilo de código y la estructura existente
- Escribir mensajes de commit claros y descriptivos
- Añadir comentarios para lógica compleja
- Actualizar la documentación según sea necesario
- Probar exhaustivamente tus cambios
- Mantener los PRs enfocados en una sola función o corrección
