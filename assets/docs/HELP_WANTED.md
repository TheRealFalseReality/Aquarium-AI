## Getting Started

1. **Fork the repository** on GitHub
2. **Clone your fork** locally
3. **Set up the development environment** (see README.md for Flutter setup)
4. **Pick an issue** or feature to work on
5. **Create a branch** for your work
6. **Make your changes** with clear, focused commits
7. **Test thoroughly** on multiple platforms if possible
8. **Submit a pull request** with a clear description
