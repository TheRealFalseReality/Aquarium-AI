# Aide recherchée : Développeurs nécessaires ! 🚀

Je ne peux faire que tellement ! **Aquarium AI** est en pleine croissance et j'ai besoin
de développeurs talentueux pour amener ce projet au niveau supérieur.

## Ce avec quoi nous avons besoin d'aide

### 1. Supprimer les publicités pour les utilisateurs payants

Nous devons implémenter un système permettant aux utilisateurs qui souhaitent soutenir
le projet de payer pour une expérience sans publicité. Cela impliquerait :

- Créer un système de paiement/abonnement
- Implémenter la logique de suppression des publicités selon le statut de l'utilisateur
- Gérer les abonnements et achats des utilisateurs
- Assurer une expérience fluide pour les utilisateurs premium

### 2. Fonctionnalités complexes d'intégration de poissons

Ajouter une intégration avancée de base de données de poissons et des fonctionnalités
intelligentes :

- Base de données de poissons améliorée avec des informations détaillées sur les espèces
- Algorithmes de compatibilité avancés prenant en compte plusieurs facteurs (tempérament,
  paramètres de l'eau, régime alimentaire, taille, etc.)
- Gestion intelligente des bacs et recommandations de peuplement
- Guides de soins spécifiques aux espèces et alertes
- Sélecteur de poissons interactif avec capacités de filtrage et de recherche
- Fonctionnalités de simulation de bac
- Identification des maladies et recommandations de traitement

## Premiers pas

1. **Forker le dépôt** sur GitHub
2. **Cloner votre fork** localement
3. **Configurer l'environnement de développement** (voir README.md pour la configuration
   Flutter)
4. **Choisir un issue** ou une fonctionnalité sur laquelle travailler
5. **Créer une branche** pour votre travail
6. **Effectuer vos modifications** avec des commits clairs et ciblés
7. **Tester soigneusement** sur plusieurs plateformes si possible
8. **Soumettre une pull request** avec une description claire

## Quelles compétences sont utiles ?

- **Flutter/Dart** – L'application est construite avec Flutter
- **Firebase** – Nous utilisons Firebase pour les services backend
- **Intégration de paiement** – Expérience avec les achats intégrés (iOS/Android)
- **Conception de base de données** – Pour la base de données de poissons et les
  systèmes de compatibilité
- **Intégration d'API** – Travailler avec des API AI (Gemini, OpenAI, etc.)
- **Conception UI/UX** – Rendre l'application belle et intuitive

## Directives de code

- Suivre le style de code et la structure existants
- Écrire des messages de commit clairs et descriptifs
- Ajouter des commentaires pour la logique complexe

- Tester soigneusement vos modifications
